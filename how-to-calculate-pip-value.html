How to Calculate Pip Value in Forex: Formulas and Examples

By Forex Profit Pathways · Updated 30 October 2026 · 7 min read
Short answer: Pip value = (pip size × position size in units) / exchange rate, where you divide by the rate only when your account currency is not the quote currency. For EUR/USD on a USD account, 1 standard lot is worth $10 per pip.

Knowing the pip value tells you how many dollars (or euros, or any account currency) each pip of movement is worth in your trade. Without it you cannot size a position or set a sensible stop loss. If the word pip is new to you, start with what a pip is in forex.

The basic formula

Pip value (in quote currency) = pip size × position size in units

Pip size is 0.0001 for most pairs and 0.01 for yen pairs. Position size in units is 100,000 for 1 standard lot, 10,000 for a mini lot, and 1,000 for a micro lot.

The result is in the quote currency (the second currency in the pair). If that is not your account currency, you convert it.

Case 1: USD is the quote currency (EUR/USD, GBP/USD, AUD/USD)

On a USD account no conversion is needed.

EUR/USD, 1 standard lot: 0.0001 × 100,000 = $10 per pip.
EUR/USD, 1 mini lot: 0.0001 × 10,000 = $1 per pip.

Case 2: USD is the base currency (USD/CAD, USD/CHF, USD/JPY)

The pip value comes out in the quote currency, so divide by the current exchange rate to get dollars.

USD/CAD example

1 standard lot at a rate of 1.3600: 0.0001 × 100,000 = 10 CAD. Then 10 / 1.36 = about $7.35 per pip.

USD/JPY example

1 mini lot at a rate of 150.00: 0.01 × 10,000 = 100 JPY. Then 100 / 150 = about $0.67 per pip.

Case 3: cross pairs (EUR/GBP, GBP/JPY, EUR/JPY)

Neither currency is USD. Calculate the pip value in the quote currency, then convert that currency to your account currency.

GBP/JPY, 1 standard lot: 0.01 × 100,000 = 1,000 JPY per pip. If USD/JPY is 150, then 1,000 / 150 = about $6.67 per pip.

Why pip value matters

Once you know the pip value, you can turn a stop loss from pips into money. A 25 pip stop on a mini lot of EUR/USD risks 25 × $1 = $25. Next, use that number to choose your position size. Common mistakes

  • Using $10 for every pair. That figure is only right for pairs where USD is the quote currency and the account is in USD.
  • Forgetting yen pairs use 0.01. Using 0.0001 gives a value 100 times too small.
  • Using an old exchange rate. Pip value moves with the rate, so a small difference is normal.
  • Ignoring the account currency. If your account is in EUR or GBP, the final conversion is different.

Frequently asked questions

What is the pip value formula?

Pip value = pip size multiplied by position size in units. If the quote currency is not your account currency, convert the result using the current exchange rate.

How much is one pip worth on EUR/USD?

On a USD account, about $10 for a standard lot, $1 for a mini lot and $0.10 for a micro lot.

Why is pip value different on USD/JPY?

Yen pairs use a pip size of 0.01 and the result is first in yen, so it has to be converted to your account currency. At a rate of 150, one standard lot is about $6.67 per pip.

Does pip value change over time?

Yes, for pairs where the pip value needs conversion. It changes slightly as the exchange rate moves.
